# Bot-of-shuati-totally-automatic
Hello！Mr.Chen

一个可在任意服务器上（此处主要是linux服务器）运行的全自动刷题小程序。目前主要面向选择题，包括单选和多选（其实同时就包含了判断题）。
此处为源码。
功能包括【收藏】【错题本】和【知识点】分析等。

---

## 快速开始

程序本体是仓库根目录的 `index.html`：**单个 HTML 文件，零外部依赖、零 CDN、零接口请求**。

- 本机使用：双击 `index.html`，`file://` 协议下即可离线运行。
- 服务器使用：把 `index.html` 放到任意静态服务器（含 Linux 服务器）的站点根目录即可，
  无需数据库、无需后端、无需安装运行时依赖。

每日按日期自动组卷 25 题（20 道单选 + 5 道多选），自动判分、自动归档错题；
单选 1 分、多选 2 分，多选少选／多选／错选均不得分，满分 30 分。

## 功能

| 功能 | 说明 |
|---|---|
| 每日组卷 | 按日期生成可复现的 25 题，优先出没做过的题 |
| 即时判分 | 交卷显示得分、正确率与逐题解析，含考点、依据、易错点、口诀 |
| 错题本 | 答错自动入本，连续答对 2 次才移出；支持按模块筛选与「只练错题」 |
| 收藏 | 答题时收藏，支持按模块筛选、只练收藏题、导出 JSON／纯文本 |
| 回看 | 「上一题」与成绩页回看，可翻本轮所有已作答题（含未作答题） |
| 题库扩充 | 内置 1065 题，提供 `window.EXTRA_QUESTIONS` 扩展接口与自定义题库导入 |
| 数据备份 | 导出／导入全量数据；进度全部保存在本机浏览器 localStorage，不联网 |
| 双端适配 | 单断点响应式布局，电脑与手机均可完整操作 |

## 一个小设计：每台设备都能重新刷一遍

这里想温柔地提醒一句：程序没有账号，也不需要登录，双击 `index.html` 就能开始。
但**题库是同一份，做题进度是各自一份**。

- **题库共用**：1065 道题全部写在 `index.html` 里。无论用手机、平板还是电脑打开，
  看到的都是同一套题，不存在「这台设备一套题库、那台设备另一套题库」。
- **进度独立**：已做过的题号、错题本、收藏、成绩记录、每日会话等 9 项数据，
  保存在各自浏览器的 localStorage 里，设备之间互不共享，也不会上传到任何服务器。
- **所以真的能刷两遍**：每日组卷会优先挑「这台设备上还没做过的题」。
  在手机上把 1065 道题刷过一轮之后，换到电脑打开，电脑上的「已做过的题号」仍是空的，
  于是又从第一题开始铺 —— 同一套题可以完整刷第二遍，解析和错题本也重新积累一遍。

这个特性是刻意保留的，不是缺陷。想二刷、三刷的人，换一台设备、换一个浏览器，
或用隐私窗口打开，都等于拿到一份干净的进度。把 `index.html` 同时放在本机
（`file://`）和服务器（`http://`）打开时，两种地址的本地存储也是分开的，各自成一轮。

反过来也有两件小事值得留意：

- 错题本和收藏**不会跨设备同步**。想搬过去，请用首页「导出数据」导出 JSON 备份，
  再到另一台设备用「导入数据」载入。
- 清除浏览器网站数据、或关掉隐私窗口后，该设备的进度会归零；
  但题库始终完好，因为题库在 `index.html` 里，不在本地存储里。

## 题库与可信度

- 全库 **1065 题**：单选 854、多选 211，覆盖马克思主义基本原理、
  毛泽东思想和中国特色社会主义理论体系概论、中国近现代史纲要、
  思想道德与法治、形势与政策以及当代世界经济与政治五个模块。
- 其中 **159 道**为 2015—2024 年考研政治单项选择题的**机构回忆版**，
  非官方出版物原文；其余为依据公开教材通识与常见命题句式原创的知识点模拟题。
- 多选题**未收录**回忆版真题：跨机构版本存在实质分歧、缺题与转录错字，
  达不到本项目的质量基线。
- 全部题目**不构成押题**，请以教育部教育考试院当年公布的大纲为准。

更完整的来源校验、脱敏清单与使用边界见 [`docs/NOTICE.md`](docs/NOTICE.md)；
程序内「命题说明与可信度声明」页也写了同样口径。
